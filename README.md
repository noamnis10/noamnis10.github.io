# האפליקציות שלי

[![CI](https://github.com/noamnis10/noamnis10.github.io/actions/workflows/ci.yml/badge.svg)](https://github.com/noamnis10/noamnis10.github.io/actions/workflows/ci.yml)

אוסף אפליקציות אישיות קטנות שרצות בדפדפן ומותקנות למסך הבית של האייפון. בלי שרת, בלי התחברות, והנתונים לא יוצאים מהטלפון.

| אפליקציה | מה היא עושה | קישור |
|---|---|---|
| **כיס** | מעקב הוצאות ותקציב יומי לסטודנט | [noamnis10.github.io/kis](https://noamnis10.github.io/kis/) |

## כיס: הכסף שלי

מספר אחד בראש המסך: **כמה מותר להוציא היום**. מתחתיו, עד איזה תאריך הכסף מספיק.

- רישום הוצאה בשלוש לחיצות, עם הבחנה בין אשראי (יורד ביום החיוב) לבין ביט, מזומן או דביט (יורד מיד)
- עסקאות בתשלומים, חיובים קבועים שנרשמים לבד, הוצאות שנתיות שמפרישים עבורן מראש
- שוברי מילואים והטבות, עם התראה לפני שהם פגים
- חובות קטנים בין חברים
- בדיקה שבועית מול היתרה בבנק
- ייבוא פירוט אשראי (Excel או CSV) שמשלים עסקאות ששכחת לרשום
- גיבוי לקובץ ושחזור ממנו, עבודה מלאה בלי אינטרנט, מצב כהה

### התקנה באייפון

1. פותחים את [noamnis10.github.io/kis](https://noamnis10.github.io/kis/) בספארי
2. לוחצים על כפתור השיתוף ובוחרים **הוסף למסך הבית**
3. מעכשיו פותחים רק מהאייקון

> **פרטיות:** הנתונים נשמרים רק בטלפון (localStorage ו-IndexedDB) ואף פעם לא נשלחים לשום מקום. ה-repo הזה ציבורי, אבל מכיל רק קוד.

## מבנה הפרויקט

```
.
├── index.html            # עמוד הבית של האתר: רשימת האפליקציות
├── kis/                  # האפליקציה כיס
│   ├── index.html        # כל האפליקציה: ממשק, חישובים ושמירה
│   ├── manifest.json     # הגדרות ההתקנה למסך הבית
│   ├── sw.js             # Service Worker לעבודה בלי אינטרנט
│   ├── icons/
│   └── lib/xlsx.min.js   # SheetJS 0.18.5 לקריאת קבצי Excel
├── tests/                # בדיקות אוטומטיות מקצה לקצה (Playwright)
├── docs/                 # תיעוד: איך החישובים עובדים
└── .github/workflows/    # CI: הבדיקות רצות בכל push
```

## פיתוח

אין שלב build. מריצים שרת מקומי ופותחים בדפדפן:

```bash
python3 -m http.server 8000
# http://localhost:8000/kis/
```

הרצת הבדיקות:

```bash
pip install -r tests/requirements.txt
python -m playwright install chromium
python -m pytest tests -q
```

הבדיקות מכסות: חישוב התקציב היומי, אשראי ותשלומים, ביטול פעולה, חיובים קבועים לאורך זמן, שמירה אחרי רענון ואחרי אובדן אחסון, ייבוא קבצים, גיבוי ושחזור, ועבודה בלי אינטרנט.

## פרסום

האתר מתפרסם אוטומטית ב-GitHub Pages מענף `main`. כל `push` לענף מעדכן את האתר תוך דקה או שתיים, והאפליקציות המותקנות מתעדכנות בפתיחה הבאה עם אינטרנט.
